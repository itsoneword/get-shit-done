  <action>
    Create `get-shit-done/bin/lib/trace.cjs` exporting a pure, testable core plus the command entrypoint:

    1. `function readTrace(cwd)` — read `path.join(cwd,'.planning','telemetry','agent-trace.jsonl')`; if absent return `[]`; else split on newline, drop blanks, JSON.parse each line (skip lines that fail to parse — best-effort), return the array of records.
    2. `function filterTrace(records, opts)` — pure function, opts = `{ session, agent, confidence, last }`:
       - if `opts.session`: keep records where `r.session_id === opts.session`
       - if `opts.agent`: keep records where `String(r.agent_type||'').startsWith(opts.agent)` (prefix match)
       - if `opts.confidence`: keep records where `String(r.confidence||'').toUpperCase() === opts.confidence.toUpperCase()`
       - apply filters first, THEN tail: return the last `opts.last` (default 20) records, preserving order
    3. `function formatTable(records)` — return a string table with columns: `ts_return  event  agent_type  confidence  seq` (confidence null rendered as `-` or `null`). Header row + one line per record.
    4. `function cmdTrace(cwd, opts, raw)` — orchestrates: `const recs = filterTrace(readTrace(cwd), opts)`; if `raw` print each record as `JSON.stringify(rec)` (one per line); else print `formatTable(recs)`. (Match the existing lib convention for how raw is handled.)
    5. `module.exports = { readTrace, filterTrace, formatTable, cmdTrace }`.

    Write `test/trace-reader.test.js` using node:test (NOT Jest). Test `filterTrace` and `formatTable` as pure functions against an in-memory array (no fs needed):
    - A fixture array of 4 records: two gsd-phase-researcher in session "s1" (confidence LOW then HIGH), one gsd-planner in "s1" (confidence null), one gsd-planner in "s2".
    - `filterTrace(recs, {session:'s1'})` returns 3 records, all session_id "s1".
    - `filterTrace(recs, {agent:'gsd-phase'})` returns the 2 researcher records (prefix match).
    - `filterTrace(recs, {confidence:'LOW'})` returns exactly 1 record.
    - `filterTrace(recs, {last:2})` returns the last 2 records in order.
    - The LOW→HIGH correlation: `filterTrace(recs, {session:'s1', agent:'gsd-phase-researcher'})` returns 2 records whose confidence values are ['LOW','HIGH'] in order.
    - `formatTable([...])` returns a string containing the header tokens "agent_type" and "confidence" and a row containing "gsd-phase-researcher".
  </action>
