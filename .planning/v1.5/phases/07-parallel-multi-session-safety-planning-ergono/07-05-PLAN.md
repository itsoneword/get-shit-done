<objective>
Build the deterministic `gsd-tools parallel-safe <A> <B>` gate in a NEW lib file. It decides whether two units (phases OR todos) can run concurrently: HARD-REFUSE on axis-B decision coupling (`depends_on` edge — unrecoverable), WARN-only on axis-A file overlap (worktrees make it reviewable at merge), GREENLIGHT when disjoint. It reads phase `depends_on` (via roadmap CLI output), the Phase 4 file-dep graph + `files_modified` union, AND the new todo `depends_on`/`related_to` edges (from Plan 07-02). Implements SC2 and the gate-reads-todos half of SC3.

The gate lives in its OWN lib file (`parallel-gate.cjs`) so `roadmap.cjs` needs no edit — the gate consumes roadmap's existing CLI output rather than reaching into it. This plan builds the gate CLI + tests; wiring it into execute-phase/discuss-phase/plan-phase workflows is Plan 07-06 (Wave 4).

- neither → decision: "greenlight", safe: true.
