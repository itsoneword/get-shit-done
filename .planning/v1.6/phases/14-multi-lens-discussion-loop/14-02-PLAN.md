**Round envelope (what the orchestrator puts in each Task() prompt — lenses consume this):**

```json

  "loop_id": "loop-<ts>-<slug>[--<run_id>]",
  "lens": "skeptic | user-advocate | architect",
  "round": 1,
  "question": "the open question being judged",
  "artifact": { "kind": "file | decision", "ref": "path or dec-NNN", "content": "full content, delimited as data" },
  "prior_positions": [],
  "output_schema": "the position-block schema, stated verbatim"
}
```

**Position block schema (LOCKED — must appear verbatim in every lens agent's output contract):**

```json
{
  "lens": "skeptic | user-advocate | architect",
  "round": 1,
  "position": "accept | reject | modify",
  "modification": "string | null — REQUIRED non-null when position is modify: the concrete change demanded",
  "blocking": true,
  "summary": "string — one-paragraph position statement",
  "constraints": [
    {
      "id": "<lens>-r<round>-c<n>  (e.g. skeptic-r1-c1, assigned by the lens)",
      "statement": "string — the downstream constraint this artifact forces or breaks",
      "anchor": "string — verbatim quote from the artifact content that grounds this constraint",
      "severity": "blocking | non-blocking",
      "status": "new | carried",
      "carries": "string | null — REQUIRED when status is carried: the prior-round constraint id this restates"
    }
  ]
}
```

**Carried/new tagging rule (LOCKED):** round 1 — every constraint is `new`. Rounds 2–3 — each constraint MUST be tagged `carried` (citing the prior-round constraint id it restates, own or another lens's) or `new`. The orchestrator validates `carries` ids against the prior-round union and rejects unknown ids.
