```json
{
  "lens": "skeptic | user-advocate | architect",
  "round": 1,
  "position": "accept | reject | modify",
  "modification": "string | null — REQUIRED non-null when position is modify",
  "blocking": true,
  "summary": "string — one-paragraph position statement",
  "constraints": [
    {
      "id": "<lens>-r<round>-c<n>  (e.g. skeptic-r1-c1)",

  ]
```

**Convergence test (LOCKED):** round N converges iff (a) no lens in round N has `blocking: true`, AND (b) zero constraints in round N have `status: "new"`.

**round_delta record shape (LOCKED):** `{type:"round_delta", loop_id, ts, round, blocking_lenses:[...], new_constraint_ids:[...], carried_count:N, converged:bool, degraded:bool}`

**Transcript record types (LOCKED):** `loop_start`, `position`, `lens_failure`, `round_delta`, `loop_end` — every record carries `loop_id`, `ts`, `type`. Location: `.planning/discuss-loop/<loop_id>/transcript.jsonl`, append-only.

**Loop id format:** `loop-<UTC ISO timestamp with : and . replaced by ->-<artifact slug, lowercased, non-alphanumeric → '-', collapsed, max 40 chars>` plus suffix `--<run_id>` when `GSD_RUN_ID` is set.

**Pure functions (exported):**

- `generateLoopId(artifactRef, runId)` — `const ts = new Date().toISOString().replace(/[:.]/g, '-')`; `const slug = String(artifactRef).replace(/[^a-z0-9]/gi, '-').replace(/-+/g, '-').replace(/^-|-$/g, '').slice(0, 40).toLowerCase()`; return `` `loop-${ts}-${slug}` `` plus `` `--${runId}` `` suffix iff runId truthy.

- `validatePositionBlock(block, opts)` where `opts = { round, priorIds (Set or array), artifactContent (string|null) }` → returns array of error strings (empty = valid). Checks, in order:
  - `block.lens` ∈ `['skeptic','user-advocate','architect']` else `"invalid lens: <value>"`
  - `block.round` strictly equals `opts.round` else `"round mismatch: block says <X>, expected <Y>"`
  - `block.position` ∈ `['accept','reject','modify']` else `"invalid position: <value>"`
  - if `position === 'modify'`: `modification` must be a non-empty string else `"modification required when position=modify"`
  - `typeof block.blocking === 'boolean'` else `"blocking must be boolean"`
  - `block.summary` non-empty string else `"summary required"`
  - `Array.isArray(block.constraints)` else `"constraints must be an array"`
  - per constraint `c`: `c.id` matches `/^(skeptic|user-advocate|architect)-r[1-3]-c\d+$/` else `"constraint <id|index>: invalid id format"`; `c.statement` non-empty; `c.anchor` non-empty string else `"constraint <id>: anchor required"`; if `opts.artifactContent` is a string and `!opts.artifactContent.includes(c.anchor)` → `"constraint <id>: anchor not found in artifact"`; `c.severity` ∈ `['blocking','non-blocking']`; `c.status` ∈ `['new','carried']`; if `c.status === 'carried'`: `c.carries` non-empty else `"constraint <id>: carries required when status=carried"`, and `carries` must be in `opts.priorIds` else `"constraint <id>: carries id <x> not in prior rounds"`.

- `computeRoundDelta(round, blocks, degraded)` → `{ type: 'round_delta', round, blocking_lenses: blocks.filter(b => b.blocking === true).map(b => b.lens), new_constraint_ids: [all c.id where c.status === 'new' across blocks], carried_count: [count of c.status === 'carried'], converged: blocking_lenses.length === 0 && new_constraint_ids.length === 0, degraded: !!degraded }`.

- `selectSurvivors(rounds)` — `rounds` is an array of rounds; each round is an array of validated blocks; the last element is the final round. Algorithm:
  1. Build `constraintMap` (id → constraint) over ALL rounds' constraints, and `ownerOf(id)` = lens prefix of the id (text before `-r`).
  2. `rootOf(c)`: walk `carries` through `constraintMap` while `status === 'carried'` and the carried id exists; return the terminal id (cycle-guard with a visited set; on missing id, return the last resolvable id).
  3. Survivors: final-round blocks where `position !== 'accept'` OR some constraint has `severity === 'blocking'`.
  4. For each final-round constraint of each final-round block, compute its root. A blocking final-round constraint of lens L is **unshared** iff no OTHER lens's final-round constraint has the same root.
  5. `weight(L)` = count of L's final-round constraints with `severity === 'blocking'` that are unshared.
  6. Return survivors as `[{ lens, weight, block }]` where `block` is the final-round block object passed through UNMODIFIED (same reference / structurally identical — never merged or rewritten), sorted by `weight` descending; ties broken by fixed order `skeptic, user-advocate, architect`.

- `appendTranscript(cwd, loopId, record)` — `dir = path.join(cwd, '.planning', 'discuss-loop', loopId)`; `fs.mkdirSync(dir, {recursive: true})`; merged = `Object.assign({}, record, { loop_id: loopId, ts: new Date().toISOString() })`; `fs.appendFileSync(path.join(dir, 'transcript.jsonl'), JSON.stringify(merged) + '\n', 'utf8')`; return the transcript path. Throws on fs failure (caller handles).

**cmd handlers (exported, mirror mailbox.cjs style — write to stdout/stderr, process.exit on error):**

- `cmdLoopId(cwd, ref)` — ref required else usage error exit 1; print `generateLoopId(ref, process.env.GSD_RUN_ID || null)`.
- `cmdValidate(cwd, opts)` — opts `{ round, jsonString, priorJson, artifactPath }`. Parse jsonString (exit 1 `"discuss-loop validate: invalid JSON — <msg>"` on failure). Parse priorJson into array (default `[]`). If artifactPath given, `fs.readFileSync` it (exit 1 if unreadable). Run `validatePositionBlock`. Errors → print one per line to stdout, exit 1. Valid → print `valid`, exit 0.
- `cmdDelta(cwd, opts)` — opts `{ round, jsonString, degraded }`. Parse JSON array (exit 1 on bad JSON or non-array). Print `JSON.stringify(computeRoundDelta(round, blocks, degraded))`, exit 0.
- `cmdSurvivors(cwd, jsonString)` — parse array-of-rounds (exit 1 on bad JSON). Print `JSON.stringify(selectSurvivors(rounds))`, exit 0.
- `cmdTranscript(cwd, loopId, jsonString)` — loopId required; parse JSON (exit 1); require a non-empty `type` field (`"discuss-loop transcript: record must have a type field"`, exit 1, no write); call `appendTranscript` in try/catch (fs failure → stderr message, exit 1); print the transcript file path, exit 0.

`module.exports = { generateLoopId, validatePositionBlock, computeRoundDelta, selectSurvivors, appendTranscript, cmdLoopId, cmdValidate, cmdDelta, cmdSurvivors, cmdTranscript }`.
