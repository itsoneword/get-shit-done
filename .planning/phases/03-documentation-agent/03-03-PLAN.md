## `init document` output (Plan 01 contract the workflow consumes)

```js
{
  mapper_model, updater_model, commit_docs,
  docs_dir, system_dir, root_map_path, gaps_path,
  root_map_exists, system_dir_exists, existing_subsystems,
  last_run_iso, has_planning, has_codebase_maps,
  commits_since, new_summaries, completed_phases_since, new_todos
}
```

## Scope decision tree (workflow executes this — not the agent)

1. `--phase N` in args → exit with error "--phase N is not supported..."
2. `--full` flag OR `!root_map_exists` → FULL mode
3. `--subsystem <name>` flag → TARGETED mode
4. `last_run_iso` non-null AND `commits_since === 0 && new_summaries.length === 0 && new_todos === 0` → prompt user "No GSD activity since last run. Run anyway? (y/n)" — default `n`
5. Otherwise → INCREMENTAL mode

## Agent invocation contracts

**FULL mode — parallel mappers:**
```
Task(subagent_type="gsd-document-mapper", model="{mapper_model}", run_in_background=true,
  description="Document subsystem {N}: {slug}",
  prompt="subsystem_slug: {slug}
boundary: {file paths / modules}
input_artifacts: {planning files + code paths}
existing_file_path: null
Write to docs/system/{slug}.md. Return confirmation only.")
```

**INCREMENTAL mode — updater two-pass:**
Pass 1 (propose): `mode=propose`, agent writes `docs/system/_proposed.md`, returns confirmation.
Pass 2 (apply, after user confirm or `--yes`): `mode=apply`, agent reads `_proposed.md`, applies edits, deletes `_proposed.md`, returns confirmation.

**TARGETED mode:** single mapper call with `subsystem_slug={name}`, `existing_file_path=docs/system/{name}.md` (if exists; else null).

## Diff preview delivery (WEAK decision from research — planner locks here)

Use `_proposed.md` scratch file always (not inline). Rationale: multi-file diffs exceed Task output size; consistent UX; easier to clean up.
